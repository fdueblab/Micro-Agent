# 金融垂域评测基准

对"想定式算法模型生成"在**经济、金融、跨境贸易垂域**的生成质量提供量化标尺：
合成数据 + 金融规则/朴素基线 + 垂域指标引擎。生成模型须**优于基线**才算达标，
防止"格式正确但只会输出多数类/朴素值"的模型蒙混过关。

## 想定一览

| 想定 | 任务 | 数据规模 | 正类率 | 基线 | 考察点 |
|------|------|---------|--------|------|--------|
| S1 跨境可疑交易监测 | 分类 | 1200 | 4% | 大额阈值规则(>1万美元) | 不平衡学习、多币种归一、规则外模式(smurfing 小额高频) |
| S2 信贷违约预测 | 分类 | 1500 | 8% | 高负债+高使用率规则 | 规则难覆盖的违约模式(低收入多次查询) |
| S3 汇率次日预测 | 回归 | 400 | - | 朴素基线(下一期=最后一期) | 时序防泄漏、方向信号提取、MAPE 不劣于基线 |
| S4 贸易单证审核 | 分类 | 800 | 15% | 币种不一致或超 50 万规则 | 四类违规识别、脏值防御(字符串金额不误报) |
| S5 制裁名单筛查 | 检测 | 300 | 40% | 精确子串匹配 | 名称模糊匹配(大小写/标点/别名变体) |

## 目录结构

```
finance/
├── scenarios.json      # 想定规格: 数据/输入列/基线规则/指标/期望
```

## 用法

```bash
# 1. 生成数据(首次使用或数据被删时)
python gen_datasets.py

# 2. 评测某个算法模型(在 Micro-Agent 根目录下)
python -m micro_agent.evaluation.finance_benchmark \
    --code workspace/benchmarks/finance/reference/s1_reference.py \
    --scenario S1_suspicious_txn

# 可选: --out report.json 保存完整报告
```

## 指标与期望

**分类想定**（S1/S2/S4/S5）：PR-AUC、KS、Recall@Precision、Accuracy。
模型输出 `classification_label` + `confidence`（对**输出标签**的置信度），
非正类行的得分按 `1-confidence` 折算为正类分。

**回归想定**（S3）：MAPE、方向准确率、朴素基线对比。
模型输出 `prediction`。期望：
- MAPE ≤ 2.0%（数据日波动 ~1.2%）
- 方向准确率 ≥ 0.52（数据含轻微动量，可提取方向信号）
- MAPE ≤ 朴素基线 × 1.05（幅度预测不劣于"明天=今天"）

**通用期望**：崩溃率 < 10%（脏输入优雅降级，不崩溃）。

## 设计原则

1. **可复现**：固定种子，任何人重跑得到同一份数据与结果。
2. **基线锚定**：每个想定内置金融规则/朴素基线，模型必须显著优于基线。
   正类中刻意混入规则难以覆盖的模式（小额拆分、低收入查询、名称变体），
   只有真正学到领域模式的模型才能拉开差距。
3. **领域真实**：正类率对齐真实业务（可疑交易 4%、违约 8%）；
   汇率日波动对齐真实量级（~1.2%）；多币种需归一（FX_RATES_TO_USD）；
   负类混入 8% 脏值考察防御性。
4. **参考实现**：每个想定提供一个参考实现（非唯一解），
   用于验证评测通道正确性，并作为生成模型的达标锚点。
